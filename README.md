# 🐾 MartinsVet — Veterinary Website

Landing page desenvolvida como projeto acadêmico da disciplina de **Desenvolvimento Web**, com o objetivo de aplicar na prática conceitos fundamentais de construção e estruturação de páginas web.

O projeto apresenta a **MartinsVet**, uma clínica veterinária e pet shop fictícia, criada para servir como contexto para o desenvolvimento da aplicação.

---

## 📚 Sobre o projeto

A **MartinsVet** é uma landing page voltada para a apresentação de serviços relacionados à saúde, higiene e bem-estar de animais de estimação.

O projeto foi desenvolvido como parte das atividades da disciplina de **Desenvolvimento Web**, permitindo colocar em prática os conhecimentos adquiridos durante as aulas.

A página apresenta informações institucionais, serviços oferecidos e uma área para contato com a clínica.

---

## 🎯 Objetivos

- Aplicar conceitos fundamentais de desenvolvimento web;
- Praticar a estruturação de páginas utilizando HTML;
- Trabalhar estilização e organização visual com CSS;
- Desenvolver uma interface clara e intuitiva;
- Organizar diferentes seções dentro de uma landing page;
- Aplicar boas práticas durante o desenvolvimento;
- Registrar minha evolução no aprendizado de desenvolvimento web.

---

## 🖥️ Funcionalidades

A landing page conta com seções destinadas a apresentar:

- 🐾 **Sobre a MartinsVet** — apresentação da clínica e de sua proposta;
- 🩺 **Consultas Veterinárias** — informações sobre atendimento e acompanhamento da saúde dos animais;
- ✂️ **Banho e Tosa** — apresentação dos serviços de higiene e cuidados;
- 🛍️ **Pet Shop** — apresentação dos produtos e serviços disponíveis;
- 📩 **Contato** — espaço destinado ao contato do usuário com a clínica.

---

## 💻 Tecnologias

As principais tecnologias utilizadas no desenvolvimento do projeto são:

- 🌐 **HTML5** — responsável pela estrutura e organização do conteúdo da página;
- 🎨 **CSS3** — utilizado para estilização, layout e identidade visual da interface;
- 🟨 **JavaScript** — utilizado para adicionar interatividade e comportamentos dinâmicos à página;
- 🔧 **Git** — utilizado para versionamento e acompanhamento das alterações realizadas no projeto;
- 🐙 **GitHub** — utilizado para armazenar, organizar e documentar o código-fonte do projeto.
